# 하이웍스 SMTP 문의용 정리

홈페이지(www.ichi.kr)에서 하이웍스 SMTP 로 메일을 보낼 때
**간격을 두고 보내는 첫 요청이 응답 없이 끊기는** 증상입니다.

---

## 문의 본문 (이대로 붙여넣으셔도 됩니다)

안녕하세요. ㈜이치입니다.

회사 홈페이지에서 하이웍스 SMTP(`smtps.hiworks.com:465`)로 메일을 발송하고 있는데,
**첫 접속이 응답 없이 끊기는 증상**이 반복됩니다. 원인 확인을 부탁드립니다.

**계정 정보**

- 발송 계정: `ichi@ichi.kr`
- 서버 / 포트: `smtps.hiworks.com` / `465` (SSL)
- 메일 환경설정 → POP3/SMTP: **사용 함**
- 허용 국가: **모든 국가 허용**

**증상**

접속 직후 서버 인사말(`220`)을 받지 못한 채 연결이 끊깁니다.
AUTH(로그인) 단계까지 가지도 못하므로 계정·비밀번호 문제는 아닌 것으로 보입니다.

같은 설정으로 **연속해서 보내면 4초 안에 정상 발송**됩니다.
한동안 쉬었다가 보내는 첫 요청만 실패합니다.

**실제 측정값** (2026-10-19, 8초 간격 연속 요청)

| 회차 | 결과 | 소요 시간 |
|---|---|---|
| 1 | 실패 (무응답) | 20.9초 (타임아웃) |
| 2 | 성공 | 4.2초 |
| 3 | 성공 | 3.8초 |

다른 시점에 측정했을 때도 같았습니다.

| 회차 | 결과 | 소요 시간 |
|---|---|---|
| 1 | 실패 (무응답) | 21.6초 (타임아웃) |
| 2 | 성공 | 4.0초 |

**발송 환경**

홈페이지는 Cloudflare Workers 에서 동작합니다.
전 세계 서버에서 요청이 나가므로 **접속 출발지 IP 가 매번 달라집니다.**
이 점이 원인과 관련이 있는지 확인 부탁드립니다.

- 특정 IP·지역의 첫 접속을 지연시키거나 차단하는 정책이 있는지
- 발송 계정에 접속 제한·차단 이력이 남아 있는지
- 고정 IP 가 아닌 환경에서 SMTP 를 쓰는 권장 방법이 있는지

감사합니다.

## 참고 — 확인된 것과 추정인 것

**확인된 사실**

- 실패는 `접속 전` 단계에서 발생 (서버 인사말 수신 실패)
- 계정·비밀번호·포트·허용 국가 설정은 정상
- 연속 요청은 4초 내 성공, 간격을 둔 첫 요청은 실패
- 2026-10-12 에는 운영에서 정상 발송된 기록이 있음

**추정 (하이웍스 답변으로 확인 필요)**

- Cloudflare Workers 는 요청마다 다른 서버에서 실행되어 출발지 IP 가 고정되지 않음
- 메일 서버가 낯선 IP 의 첫 접속을 지연·차단하고, 한 번 통과하면 일정 시간 허용하는 것으로 보임

**무효한 측정 (참고용)**

가입되지 않은 이메일로 테스트하면 서버가 메일을 보내지 않고 바로 성공을 돌려줍니다
(가입 여부를 숨기기 위한 정상 동작). 측정은 **가입된 계정**으로만 해야 유효합니다.

## 답변과 무관하게 할 수 있는 조치

메일 발송에 **재시도**를 넣으면 대부분 해결됩니다.

```
현재   1회 시도 · 타임아웃 20초  →  실패하면 그대로 오류
개선   타임아웃 8초 · 최대 2회   →  첫 실패 후 재시도
```

측정값상 두 번째 시도는 4초 내에 성공하므로, 최악의 경우에도 12초 안에 끝납니다.
다만 이는 증상을 덮는 처방이고 근본 원인 해결은 아닙니다.
